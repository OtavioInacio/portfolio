# OTÁVIO.DEV — Portfólio

Portfólio pessoal de Otávio Henrique, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades
- Layout responsivo para desktop, tablet e celular.
- Tema escuro/claro com preferência salva no navegador.
- Conteúdo em português e inglês.
- Navegação mobile.
- Animações de entrada com Intersection Observer.
- Fundo animado com Particles.js (respeita a preferência por movimento reduzido).
- Atalhos de contato pelo WhatsApp, LinkedIn, GitHub e e-mail.
- Seções de serviços, projetos, apresentação e contato.

## Tecnologias
- HTML5, CSS3 e JavaScript (Vanilla).
- [Lucide](https://lucide.dev/) para ícones.
- [Devicon](https://devicon.dev/) para ícones de tecnologias.
- [Particles.js](https://vincentgarreau.com/particles.js/) para o fundo animado.

## Visualização local
Abra o arquivo `index.html` no navegador. Para uma experiência mais próxima da hospedagem, utilize a extensão Live Server do VS Code.

## Publicação
O projeto pode ser publicado pelo GitHub Pages. Os arquivos `index.html`, `style.css`, `script.js` e os currículos devem permanecer na mesma pasta.
